# 후쿠오카 여행 노트

여행 준비부터 여행 중 확인까지 한 곳에서 쓰는 개인용 웹사이트입니다.
빌드 없이 HTML/CSS/JS만으로 동작하고, GitHub Pages에 올려 폰에서 앱처럼 씁니다.

- 사이트: https://ms63-v0.github.io/fukuoka-trip/
- 여행 날짜는 코드에 넣지 않았어요. 앱의 **준비 → 여행 정보**에서 정하면 동기화로 모든 기기에 퍼집니다.

## 폰에서 쓰기

1. 폰 브라우저로 사이트를 엽니다.
2. **홈 화면에 추가** (아이폰 Safari: 공유 → 홈 화면에 추가 / 안드로이드 Chrome: ⋮ → 홈 화면에 추가). 앱처럼 전체 화면으로 열리고, 한 번 연 화면과 지도는 오프라인에서도 보여요.
3. PC에서 **준비 → 기기 동기화 → QR로 폰 연결**을 누르고 폰 카메라로 찍으면 연결돼요. (또는 코드를 직접 입력)

## 기기 동기화

- 처음 한 기기에서 **이 기기 데이터로 시작**을 누르면 25자리 동기화 코드가 생겨요. 다른 기기는 그 코드로 연결합니다.
- 저장할 때마다 몇 초 뒤 자동으로 올라가고, 앱을 다시 볼 때와 1분마다 다른 기기 변경을 받아요.
- 두 기기에서 동시에 고쳐 어긋나면 어느 쪽을 남길지 물어봐요.
- 오프라인에서도 계속 쓸 수 있고, 연결되면 올라가요.
- 동기화 코드(와 QR, 연결 링크)는 비밀번호처럼 다뤄 주세요. 코드를 아는 사람은 데이터를 보고 고칠 수 있어요.
- 서버: Supabase 무료 프로젝트. 테이블은 공개 키로 직접 접근할 수 없고, 코드의 해시로만 찾는 함수 두 개(`supabase/schema.sql`)만 열려 있어요. 무료 프로젝트는 일주일 동안 요청이 없으면 일시정지되니, 오래 안 쓰면 Supabase 대시보드에서 다시 켜 주세요.

## 로컬 실행

```bash
python serve.py
```

http://localhost:5180 을 엽니다. (로컬 주소와 배포 주소는 저장 공간이 따로라서, 같은 데이터를 보려면 둘 다 동기화 코드로 연결하세요.)

## 화면 구성

| 화면 | 하는 일 |
| --- | --- |
| **홈** | 동선 지도 + 날짜별 타임라인. 일정 순서대로 번호 핀과 경로 선, 숙소 핀, 일정에 없는 저장 장소. 여행 중에는 "지금 / 다음" 카드와 길찾기 버튼. 날씨(Open-Meteo), D-day, 엔↔원 계산기 |
| **일정** | Day별 일정 추가·수정·순서 변경·완료 체크. 장소 간 거리/도보 시간 자동 계산, 이동수단 직접 입력, **영업시간 충돌 경고**(휴무·영업 전·브레이크), 구글맵 경로 열기, 일정에 없는 장소 바로 넣기 |
| **리스트** | 맛집 · 카페 · 쇼핑 · 방문 · 기타 카테고리별 **2열 카드**. 검색, 필터(꼭 가기/미배정/방문 전·후), 정렬, 카드별 지금 영업 상태·여행 중 휴무일·Day 표시. 넓은 화면에서는 오른쪽에 지도 |
| **장소 상세** | 구글맵·길찾기·네이버지도·전화, 요일별 영업시간(여행 요일 강조) + 브레이크·라스트오더, 웨이팅/예약, 메뉴(엔화+원화), 쇼핑 체크리스트, 주소 복사, 미니 지도, 메모 |
| **준비** | 여행 날짜·환율, 항공편, 숙소(지도 핀), 기기 동기화, 준비 체크리스트, 정보 메모, 비상 연락처, 테마, JSON 내보내기/불러오기 |

## 장소 위치 넣는 법

1. **구글맵 링크 붙여넣기**: 장소 페이지의 긴 주소(`google.com/maps/place/...`)를 붙이면 좌표와 이름을 가져옵니다. `maps.app.goo.gl` 짧은 링크에는 좌표가 없어서, 링크를 한 번 열고 주소창의 긴 주소를 복사하세요.
2. **주소로 찾기 / 현지 이름으로 찾기**: OpenStreetMap 검색이라 번지까지는 안 잡힐 수 있어요. 그 경우 동네(초메) 단위로 찾아 주니 핀을 끌어서 맞추면 됩니다.
3. **지도를 탭**해서 직접 핀을 꽂거나 핀을 끌어서 옮길 수 있어요.

## 파일 구조

```
index.html            진입점
manifest.webmanifest  홈 화면 앱 설정
sw.js                 서비스 워커 (오프라인 캐시)
icons/                앱 아이콘
css/app.css           디자인 토큰(라이트/다크) + 전체 스타일
js/config.js          Supabase 주소·공개 키, 사이트 주소
js/core.js            유틸, 영업시간 계산, 링크 생성, 아이콘, 시트
js/store.js           데이터 구조, 로컬 저장, 예시 데이터
js/sync.js            기기 동기화
js/geo.js             지도·마커, 주소 검색, 구글맵 링크 해석, 날씨, 위치 선택기
js/places.js          카드, 리스트, 장소 상세
js/place-form.js      장소 추가/수정 폼
js/plan.js            일정 화면, 일정 폼, 동선 분석
js/home.js            대시보드
js/info.js            준비 화면
js/app.js             앱 셸, 라우터, 테마
supabase/schema.sql   동기화용 테이블·함수
serve.py              로컬 미리보기 서버
```

## 외부 서비스

- 동기화: Supabase (공개 키만 사용)
